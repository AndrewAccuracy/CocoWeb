# 风险分析记录

## 模块范围

本次选择对 `郎竞茗_CNN_ImageClassification` 中的 CNN 图片分类功能进行安全加固，重点关注用户上传图片并触发模型预测的入口。

## 涉及的敏感操作

1. 接收用户上传文件。
2. 读取、解析和转换图片内容。
3. 调用本地模型进行预测。
4. 向用户返回预测结果或错误信息。

## 主要安全风险

| 风险 | 可能后果 | 加固方向 |
| --- | --- | --- |
| 不限制上传文件类型 | 上传脚本、伪装文件或异常文件，造成后续解析风险 | 只允许 `jpg/jpeg/png`，并校验真实图片内容 |
| 直接使用原始文件名保存 | 路径穿越、覆盖项目文件、污染工作目录 | 不信任用户文件名，不使用用户文件名落盘 |
| 不限制文件大小和图片尺寸 | 资源消耗过高，可能造成拒绝服务 | 限制 5MB、最大像素数和最大宽高 |
| 只依赖扩展名判断类型 | 伪造后缀绕过校验 | 使用图片解码和文件头检测进行双重校验 |
| 返回原始异常信息 | 暴露服务器路径、模型文件名、代码结构 | 统一返回安全错误信息，详细异常仅写日志 |

## 安全目标

- 上传入口只接受真实、合理大小的图片。
- 上传处理不产生用户可控路径写入。
- 预测失败时不泄露内部异常、路径或模型信息。
- 加固逻辑有测试和审查记录支撑。
