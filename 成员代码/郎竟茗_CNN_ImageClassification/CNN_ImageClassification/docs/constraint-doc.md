# 项目约束文档

以下内容在每次开启新的 AI 对话时完整提供，避免 AI 遗忘安全边界。

## 背景

项目为 CNN 图片分类功能，用户上传图片后由模型返回分类结果。本次任务不是新增复杂业务，而是对已有图片上传和预测入口进行安全加固。

## 任务范围

1. 加固图片上传输入处理。
2. 校验图片扩展名、真实类型、大小和尺寸。
3. 避免使用用户上传文件名作为服务器路径。
4. 统一错误响应，避免暴露内部异常。
5. 增加必要测试和过程文档。

## 必须满足的安全约束

1. 只允许 `jpg`、`jpeg`、`png`。
2. 文件大小不得超过 5MB。
3. 图片宽高不得超过 4096x4096，像素总数不得超过 10000000。
4. 不得把用户原始文件名拼接进服务器路径。
5. 不得将异常堆栈、服务器绝对路径、模型路径返回给用户。
6. 校验失败必须停止预测流程。
7. 加固逻辑必须可测试，至少覆盖合法图片、伪造图片、非法扩展名、路径穿越文件名、过大文件和预测异常。

## 禁止行为

1. 禁止仅靠文件扩展名判断上传内容。
2. 禁止直接 `save(upload.filename)`。
3. 禁止在响应中返回 `traceback`、`repr(exception)` 或本地路径。
4. 禁止为了方便测试而关闭安全校验。
5. 禁止把安全要求只写在注释里而不落实到代码逻辑。
