# 安全审查清单

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 是否明确模块边界 | 通过 | 边界为 CNN 图片上传和预测入口 |
| 是否限制上传类型 | 通过 | 仅允许 `jpg/jpeg/png` |
| 是否校验真实图片内容 | 通过 | 使用文件头检测和 Pillow 解码校验 |
| 是否限制上传大小 | 通过 | 最大 5MB |
| 是否限制图片尺寸/像素 | 通过 | 最大 4096x4096，像素总数 10000000 |
| 是否避免路径穿越 | 通过 | 不使用用户文件名落盘，并拒绝含路径片段的文件名 |
| 是否避免异常信息泄露 | 通过 | 用户侧只返回统一错误，内部异常写日志 |
| 是否在校验失败后停止预测 | 通过 | 抛出 `SecurityValidationError` 并直接返回错误 |
| 是否有测试覆盖 | 通过 | 覆盖合法图片、非法扩展、伪造图片、路径穿越、过大请求、预测异常 |
| 是否只把安全要求写在注释中 | 通过 | 安全约束已落实在代码分支和测试中 |

## 人工审查结论

本次改动符合最小暴露原则：上传入口不信任用户输入，不把内部错误细节暴露给外部用户；模型预测只在输入通过安全校验后执行。
