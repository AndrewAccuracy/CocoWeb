# Prompt 记录

## Prompt 1：确定加固方向

```text
我需要完成信息安全管理课程作业三。仓库中我的部分是
成员代码/郎竞茗_CNN_ImageClassification。
请选择“安全加固已有问题代码”方向，围绕 CNN 图片分类项目中用户上传图片并预测的入口，
分析可能存在的安全问题，并给出可落地的加固方案。
要求关注输入校验、文件上传安全、路径穿越、资源消耗、错误响应和可测试性。
```

## AI 输出中采用的安全约束

```text
图片上传入口不应直接信任用户文件名和扩展名。
应限制文件大小、允许的图片格式、图片尺寸和像素总数。
应使用图片解码校验真实内容，校验失败时停止预测。
预测异常应返回统一错误信息，不能暴露服务器路径、模型路径或堆栈。
```

## Prompt 2：生成加固代码

```text
请为 CNN 图片分类上传入口生成一个 Python 安全加固模块。
要求：
1. 只允许 jpg/jpeg/png；
2. 上传大小不超过 5MB；
3. 不使用用户文件名保存文件；
4. 用 Pillow 校验真实图片内容；
5. 限制最大宽高和像素数量；
6. 提供安全的预测包装函数；
7. 预测失败时返回统一错误信息，不返回内部异常；
8. 给出 Flask 路由接入示例。
```

## AI 输出中采用的关键片段

```text
validate_and_open_image(file_obj, filename, declared_size=None)
predict_image_safely(file_obj, filename, model_predict, declared_size=None)
```

关键安全逻辑包括：

- 检查文件名中是否包含 `/`、`\`、`..`。
- 限制扩展名为 `jpg/jpeg/png`。
- 使用 `imghdr.what` 和 `Pillow Image.verify()` 双重校验。
- 设置 `Image.MAX_IMAGE_PIXELS`。
- 捕获异常后只返回“预测失败，请稍后重试。”。

## Prompt 3：发现偏差后的修正

```text
上一版方案只检查了扩展名，仍可能被伪造后缀绕过。
请补充真实图片内容校验，并增加测试覆盖伪造图片、路径穿越文件名和模型异常信息泄露。
```

## 修正结果

已补充：

- `imghdr.what(None, data)` 文件头类型判断。
- `Image.open(...).verify()` 图片解析验证。
- 单元测试覆盖伪造图片、路径穿越、非法扩展名、过大请求和预测异常。
