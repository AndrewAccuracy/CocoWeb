# 整改前后对比说明

## 整改前

可能存在的问题：

1. 上传入口可能只检查扩展名或不检查类型。
2. 上传文件名可能被直接用于保存路径。
3. 图片大小、尺寸和像素数量缺少统一限制。
4. 解析或预测异常可能直接返回给用户。
5. 缺少针对上传安全的测试记录。

## 整改后

本次 PR 新增统一安全入口：

```text
security/secure_image_input.py
```

加固效果：

1. 只允许 `jpg/jpeg/png`。
2. 文件内容必须能被识别和解码为真实图片。
3. 不使用用户上传文件名落盘，降低路径穿越风险。
4. 限制上传大小、图片尺寸和像素数量。
5. 预测异常统一返回，不暴露内部细节。
6. 增加单元测试证明关键安全约束生效。

## 对比结论

整改后，图片上传和预测流程从“信任用户输入后直接处理”调整为“先校验、再预测、统一响应”，更符合输入处理和错误响应安全要求。
