# 鸿蒙商城认证模块 — 安全风险识别报告

**模块范围：** `AuthService`、`AuthFilter`、`AuthController` 及关联的用户会话与密码校验逻辑  
**分析人员：** 张亦潮  
**分析日期：** 2026-06-27  
**分析方法：** STRIDE 威胁建模 + OWASP ASVS L1 对照审查

---

## 1. 模块功能与敏感操作概述

本模块负责用户身份认证与访问凭证管理，涉及以下敏感操作：

| 操作 | 接口/组件 | 敏感数据 |
|------|-----------|----------|
| 用户登录 | `POST /wx/auth/login` | 用户名、密码（凭据） |
| 身份校验 | `AuthFilter` | 访问令牌（Token） |
| 用户信息获取 | `GET /wx/auth/info` | 用户 PII（昵称、手机号、头像） |
| 会话注销 | `POST /wx/auth/logout` | 访问令牌 |
| 受保护业务访问 | 订单/购物车/地址等 Controller | 用户身份上下文 |

---

## 2. 威胁识别（STRIDE）

### 2.1 Spoofing（身份伪造）

| 编号 | 威胁描述 | 原代码表现 | 风险等级 |
|------|----------|------------|----------|
| T-S01 | 无签名 Token 可被伪造 | 使用 UUID 随机串作为 Token，不含密码学签名，攻击者无法验证 Token 合法性 | **高** |
| T-S02 | Token 传递方式非标准 | 使用自定义 Header `x-litemall-token`，缺少 `Authorization: Bearer` 规范 | **中** |

### 2.2 Tampering（篡改）

| 编号 | 威胁描述 | 原代码表现 | 风险等级 |
|------|----------|------------|----------|
| T-T01 | 无 Token 完整性保护 | UUID Token 不包含 Claims，无法检测篡改 | **高** |

### 2.3 Repudiation（抵赖）

| 编号 | 威胁描述 | 原代码表现 | 风险等级 |
|------|----------|------------|----------|
| T-R01 | 会话缺乏审计字段 | Token 生成未记录 jti/签发时间等可追溯信息 | **低** |

### 2.4 Information Disclosure（信息泄露）

| 编号 | 威胁描述 | 原代码表现 | 风险等级 |
|------|----------|------------|----------|
| T-I01 | 密码明文传输 | 登录请求以 HTTP JSON Body 传输明文密码，无 TLS 强制 | **高** |
| T-I02 | 明文密码存储兼容 | `AuthService.login()` 存在 `rawPassword.equals(user.getPassword())` 明文比对分支 | **高** |
| T-I03 | 错误响应信息泄露 | 登录失败统一返回"账号或密码错误"（已符合最小披露原则） | **低** ✓ |

### 2.5 Denial of Service（拒绝服务）

| 编号 | 威胁描述 | 原代码表现 | 风险等级 |
|------|----------|------------|----------|
| T-D01 | 无登录频率限制 | 登录接口缺少速率限制，存在暴力破解可能 | **中** |

### 2.6 Elevation of Privilege（权限提升）

| 编号 | 威胁描述 | 原代码表现 | 风险等级 |
|------|----------|------------|----------|
| T-E01 | 鉴权逻辑分散，存在遗漏风险 | `AuthFilter` 仅解析 Token 但不拦截，`各 Controller` 各自判空 | **高** |
| T-E02 | 未登录可访问部分敏感接口 | 若 Controller 遗漏 `needLogin()` 检查，Filter 不会兜底 | **高** |

## 3. OWASP ASVS 对照（节选）

| ASVS 条款 | 要求 | 原实现状态 |
|-----------|------|------------|
| V2.1.1 | 凭据传输需加密通道保护 | ❌ 未强制 HTTPS |
| V2.2.1 | 密码存储使用自适应哈希 | ⚠️ 有 BCrypt 但保留明文回退 |
| V3.2.1 | 会话 Token 具备完整性验证 | ❌ UUID 无签名 |
| V4.1.1 | 访问控制集中 enforced | ❌ 分散在各 Controller |
| V7.1.1 | 错误响应不泄露敏感信息 | ✓ 已满足 |

---

## 4. 风险优先级与整改方向

| 优先级 | 风险编号 | 整改措施 |
|--------|----------|----------|
| P0 | T-I02 | 移除明文密码比对，强制 BCrypt 校验 |
| P0 | T-S01, T-T01 | 引入 HS256 签名的 JWT 替代 UUID Token |
| P0 | T-E01, T-E02 | AuthFilter 统一拦截受保护路径，返回 401 |
| P1 | T-I01 | 部署层强制 HTTPS，配置文档说明 |
| P1 | T-S02 | 支持 `Authorization: Bearer` 标准头 |
| P2 | T-D01 | 后续迭代增加登录速率限制（本次不纳入范围） |

---

## 5. 结论

原认证模块存在**身份伪造、凭据泄露、访问控制绕过**三类高风险问题，不符合 OWASP ASVS 对身份验证与会话管理的基本要求。本次整改将以 JWT 签名令牌 + 统一鉴权拦截 + 强制 BCrypt 为核心目标进行安全加固。
